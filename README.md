# YOLOv8s Project

Este repositorio contiene el código y datos con los que se entrenó un modelo personalizado utilizando la arquitectura YOLOv8s.

## Archivos y Datos

Debido a que la computadora donde se está realizando este código no tiene acceso a GPU, se migró el proyecto a Google Colab. En los siguientes enlaces se encuentra el código final, junto con los datos usados y los modelos generados con las arquitecturas probadas:

### Google Colab
Notebook con el código completo del proyecto:
